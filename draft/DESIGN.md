# 焕羽 Skills 设计说明

> 更新日期：2026-10-17。本文记录用户已确认保留的最新设计，以本目录的 `index.html`、`styles.css`、`app.js`、`skills.js` 和实际截图为依据。本文不修改界面，也不记录已清理的历史方案。

## 1. 产品定位与设计目标

焕羽 Skills 是焕羽开发的 AI Agent Skills 商业化平台，承载技能发现、交付效果展示、开源获取与专业授权入口。商品目录会持续扩展，当前展示的商品数量不是平台容量或业务范围的限制。

页面优先帮助访问者判断技能是否适合自己的工作。浏览、分类、搜索和查看交付示例无需登录；访问专业授权管理时再打开账户窗口。

核心浏览路径：

1. 理解平台提供什么：为工作找到可用的技能。
2. 通过分类或搜索找到商品，了解用途与版本。
3. 在商品原位展开，比较输入与交付内容。
4. 前往 GitHub 获取开源技能，或进入账户管理专业授权。

## 2. 已确认的视觉方向

采用「金石雕版 × 高精工学」方向，以墨黑底色、骨白文字、纸白交付稿和少量朱砂形成识别。传统印刷的材质与宋体表达品牌气质，现代目录、明确的操作与对齐关系承担平台功能。

当前确认的主视觉为墨黑木活字特写。它表达字面凸起、磨损边缘、木纹和侧向光照；不能替换成砚台、墨锭或其他仅具有古典氛围的器物。

- 主图：`assets/movable-type-hero.png`，1672 × 941，保留原文件。
- 来源：依据用户提供的活字照片生成，不作为历史文物实拍使用。
- 参考与生成说明：`assets/SOURCES.md`、`assets/GENERATION.md`。
- 当前不展示单字方块式商品图标；商品识别依靠名称、英文标识、用途和分类。

用户已确认满意当前视觉。后续以具体产品需求为修改依据，保留当前构图与图片，不再以评审分数推动整体改版。

## 3. 页面结构与阅读层级

| 区域 | 内容与行为 | 视觉作用 |
| --- | --- | --- |
| 页头 | 焕羽印章与品牌、技能商店、装配指南、关于焕羽、登录与注册 | 建立品牌与稳定入口 |
| 首屏 | 「为工作，找到好技能。」、平台说明、活字主图、「浏览技能」锚点 | 以大字与材质形成第一印象 |
| 技能商店 | 动态数量、分类、搜索、商品列表、原位交付预览 | 完成商品发现与判断 |
| 获取与管理 | 「按需选择，统一管理。」、开源仓库、授权中心、装配指南 | 提供开源与专业授权两条路径 |
| 页脚 | 品牌、版权、我的授权、回到顶部 | 收束页面并提供辅助入口 |
| 按需弹窗 | 技能版本、登录／注册、条款与隐私说明 | 在需要时补充细节，不占用默认浏览空间 |

「关于焕羽」目前定位到页脚品牌与维护信息，尚无独立关于页面。页面中的示例是静态交付内容，不是在线运行技能的结果。

## 4. 视觉系统

### 色彩与表面

以下为当前主要可见色值，具体组件仍以 `styles.css` 的最终级联为准；它们不是另行引入的一套主题变量。

| 用途 | 代表色值 | 使用原则 |
| --- | --- | --- |
| 页面墨黑底色 | `#101110` | 承载主体内容，保持整体安静 |
| 首屏骨白标题 | `#f0ebdf` | 用于品牌主张和高层级文字 |
| 交付稿纸面 | `#e9e5db` | 集中用于展开的输入／交付内容，形成明暗切换 |
| 纸面关键文字 | `#323b2c` | 保持纸白区域的清晰阅读 |
| 朱砂主操作 | `#a43b2a` | 用于授权入口等关键行动 |
| 展开商品名 | `#e3b093` | 标示当前阅读对象 |
| 开源入口文字／边框 | `#e6e9dd` / `#8d9681` | 描边按钮，与朱砂授权按钮区分 |

表面以平直边缘、细分隔线和克制的颗粒感为主。朱砂集中承担行动或状态，避免把每一层信息都染成强调色。

### 字体与字号

- **品牌、首屏、商品中文名与交付标题**：宋体系统，主要使用 Noto Serif SC 与系统回退，建立印刷感。
- **导航、用途说明、分类、搜索及操作说明**：当前最终规则主要使用 Microsoft YaHei / sans-serif，优先保证功能文字可读。
- **技能英文标识与命令**：等宽字体系统，便于辨认稳定标识和终端内容。
- 本地保留样式实际引用的 Noto Sans CJK 原字体、字符子集与许可；部分字体仍通过 Google Fonts 加载，离线时使用回退字体。

宽屏代表性尺度：首屏第一行约 63px、第二行约 96px；商品中文名约 33px；商品用途与交付正文约 16px；交付标题约 32px。中屏与手机使用独立断点缩减字号和间距，不通过整体缩放页面适配。

### 构图与间距

桌面首屏采用非对称编排：导语在左上，标题位于左下，活字图占右侧，通过底部渐隐融入墨黑背景。浏览入口位于标题下方，采用文字与细朱砂下划线。

商店采用侧边分类与主目录两条轴线。商品名、用途和右侧加减号按列对齐；展开内容紧接该商品，纸白底上的输入与交付分栏呈现。底部获取区沿目录内容轴线排布。

## 5. 商品目录与统一交互

所有 Skill 共用一套商品行和原位展开模板，Oracle-bone 与其他商品完全一致。

- 默认全部收起，右侧显示「＋」；点击整行展开该商品，下方显示输入、说明与交付稿，符号变为「−」。
- 再次点击收起；展开另一商品时，先前商品收起。交付内容不移到首屏或独立展示区。
- 展开区提供「版本与授权」及「复制示例」；前者打开该商品详情，后者复制交付区域文字并短暂显示复制状态。
- 商品详情读取同一份商品数据，展示名称、标识、分类、说明和版本。
- 分类由已展示商品自动生成；搜索覆盖名称、标识、用途、分类与关键词，不区分大小写。
- 结果数量按当前筛选动态计算；无结果时显示空状态和清除入口。
- 初始显示最多 8 项，通过「显示更多技能」逐批增加 8 项。切换分类或搜索时重置分页并收起预览。

数据源为 `skills.js` 的 `window.HUANYU_SKILLS`。新增商品不应复制页面结构或新增专属展开逻辑。字段与前台展示控制详见 [SKILLS-CATALOG.md](SKILLS-CATALOG.md)。

## 6. 开源与专业授权

底部保留「按需选择，统一管理。」标题，说明开源获取与账户管理的分工。

| 入口 | 当前表现 | 目标与边界 |
| --- | --- | --- |
| 浏览开源 Skills | 带 GitHub 图标的描边链接 | 新标签打开 https://github.com/Huanyu-Hibiki/Huanyu-Skills ，使用 `noopener noreferrer` |
| 进入授权中心 | 朱砂实底按钮 | 打开登录弹窗；尚无真实授权中心页面 |
| 装配指南 | 原位展开的说明 | 展示并复制现有 CLI 命令，不代表已验证真实安装服务 |

两条获取路径保持可见，不能只保留付费账户入口。开源跳转无需先登录平台。

## 7. 响应式与可访问性

- **宽屏（大于 1000px）**：使用首屏定位构图、左侧分类、右侧目录和双栏交付预览；1001–1200px 缩减标题与列宽。
- **中屏**：分类与搜索重新排布，逐步缩减列间距，交付预览根据可用宽度调整。
- **手机（560px 及以下）**：品牌与账户入口保留，主导航隐藏；标题、图片、导语与浏览按钮依次排列。分类横向排列并允许换行，搜索占据可用宽度；商品名和用途上下排布，输入与交付上下排列。
- **更窄屏（360px 及以下）**：进一步减少字号与内边距，保证名称、正文和按钮不溢出。

交互使用原生按钮、链接、输入框与 `details`。商品展开设置 `aria-expanded`、`aria-controls`，分类设置 `aria-pressed`，搜索具有可访问名称，结果数量提供状态播报。弹窗支持 Esc 关闭、Tab 焦点约束、背景禁用与关闭后焦点返回；页面保留可见的键盘焦点样式。

## 8. 动效

使用本地 GSAP 与 ScrollTrigger：

- 首屏文字短距离上移入场，透明度渐显；图片轻微缩放入场。
- 滚动首屏时，图片轻微位移、缩小并降低透明度。
- 商品目录与底部行动区短距离进入视野。
- 账户弹窗与提示使用轻量透明度过渡。

GSAP 动效仅在 `prefers-reduced-motion: no-preference` 下运行；样式保留减少动态效果处理。动效不应阻碍商品浏览或改变内容顺序。

## 9. 当前实现与边界

当前为静态前台原型，技术组成是 HTML、CSS、Alpine.js、GSAP 和本地商品数据，无生产构建要求。

已实现的本地交互包括目录筛选、搜索、分页、统一展开、版本详情、复制、账户表单演示、密码显隐、邮箱记忆及弹窗控制。

未接入真实账户、GitHub OAuth、密码重置邮件、商品后台上架、订单、支付、授权签发或模型执行。`listed` 仅控制本地前台展示，不等同于后台发布流程。版本弹窗中的权益文案仍需在商业上线前核定，不能作为服务已交付的证明。
