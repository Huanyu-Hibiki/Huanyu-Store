# 技能商店商品目录

这是焕羽开发的 Skill 商业化平台前台，不是固定三件作品的作品集。当前商品只代表现有目录，不限定未来数量。

## 新增与下架

商品唯一数据源是 `skills.js` 中的 `window.HUANYU_SKILLS`。新增商品时添加一条记录，不需要修改首页 HTML、详情查找或展开组件。

- `id`：唯一、稳定的技能标识，例如 `new-skill`。
- `title`、`description`：商品名称和用途。
- `category`：分类；分类入口由已展示商品自动生成。
- `listed`：是否在前台目录展示；未展示记录不会出现在搜索、分类或详情查找中。
- `keywords`：搜索关键词。
- `editions`：该商品提供的版本，例如开源基础版、专业授权。
- `preview`：输入、说明、输出标题和段落；所有商品使用相同的原位展开模板。

搜索、分类、结果数量和每批 8 项的“显示更多”都根据数据计算。商品详情也查找同一份目录，新增商品不需要补写一套详情映射。

## 当前实现边界

`listed` 是本地前台配置，不是后台发布服务。此轮没有实现管理后台、订单、支付、真实账户或授权签发，也没有虚构售价。后续接入商品 API 时可替换目录加载来源，复用现有目录与预览模板。

验证：`node --test tests/catalog.test.cjs` 覆盖新增第四款商品、未上架记录、超过一页的目录、分类和大小写搜索。
